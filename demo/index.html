02 / Capabilities

What the library provides

Four distinct locales

Pashto, Afghan Dari, Iranian Persian and English, including local month names and complete weekday labels.

Two calendar systems

Browse Solar Hijri or Gregorian dates while maintaining Gregorian ISO values for storage.

Fast month/year navigation

Select months from a 12-month grid and years from pages of 12, with bounds-aware navigation.

Flexible UI

Right-to-left support, light/dark themes, native HTML forms, keyboard navigation and range limits.

03 / Get started

Installation and local development

Release status: this project is available on GitHub as an early implementation. It has not been published to the npm registry yet. Use the source build or a local npm tarball for now.

Clone, install and build

Terminal 
git clone https://github.com/fidatech/afghan-datepicker.git
cd afghan-datepicker
npm install
npm run check
python3 -m http.server 4173

Open http://localhost:4173/demo/. Node.js 20+ and Google Chrome/Chromium are required for the complete browser test suite. Run npm run build to compile without browser tests.

Install a local package tarball in another application

Terminal 
# Inside afghan-datepicker/
npm run build
npm pack

# Inside your application's directory:
npm install /absolute/path/to/afghan-datepicker/fidatech-afghan-datepicker-0.2.0-beta.1.tgz

The tarball includes the compiled JavaScript, TypeScript declarations and CSS. Once an official npm release exists, standard registry installation will be documented here.

04 / Usage

Vanilla JavaScript and TypeScript

Once the package tarball is installed, create a normal input, import the library and import its stylesheet through your bundler.

HTML 
<label for="due_date">Due date</label>
<input id="due_date" name="due_date" />
TypeScript 
import { AfghanDatepicker } from '@fidatech/afghan-datepicker';
import '@fidatech/afghan-datepicker/styles.css';

const picker = new AfghanDatepicker('#due_date', {
  locale: 'ps-AF',
  calendar: 'jalali',
  min: '2024-01-01',
  max: '2030-12-31',
  theme: 'light',
  onChange: (iso) => console.log(iso)
});

// Returns 'YYYY-MM-DD' or null:
console.log(picker.getValue());

For this repository's own demo, demo/index.html imports ../dist/index.js directly after a local build.

05 / Localization

Languages, calendars and date storage

The default calendar is jalali, but you may set calendar: 'gregorian'. Weekdays start on Saturday by default (weekStartsOn: 6). The Pashto and Dari date headers use full weekday labels without abbreviations.

Storage rule: user-facing dates may use Solar Hijri year/month/day and Persian numerals, while submitted form values always use Western digits in Gregorian YYYY-MM-DD. This library does not convert an ISO date into a timestamp or UTC moment.

07 / JavaScript API

Methods and lifecycle

JavaScript 
picker.getValue();         // '2026-10-19' or null
picker.setValue('2026-10-19');
picker.setValue(null);      // Clear the selection
picker.open();              // Open the calendar
picker.close();             // Close the calendar
picker.destroy();           // Remove events and generated DOM

// Callback (only fires when selection changes):
new AfghanDatepicker('#due_date', {
  onChange: (iso) => console.log(iso)
});

setValue() accepts Gregorian ISO dates only; invalid values or dates outside the configured bounds cause a RangeError. Call destroy() before removing/replacing the associated input in a reactive framework.

08 / Backend integration

HTML forms and Laravel Blade

When an input has a name, the datepicker creates a hidden form input using that same name. Its value is always Gregorian ISO, making validation and database storage straightforward.

resources/views/invoices/create.blade.php 
<form method="POST" action="{{ route('invoices.store') }}">
  @csrf
  <label for="invoice_date">Invoice date</label>
  <input id="invoice_date" name="invoice_date"
         value="{{ old('invoice_date') }}">
  <button type="submit">Save</button>
</form>
resources/js/app.ts (with Vite) 
import { AfghanDatepicker } from '@fidatech/afghan-datepicker';
import '@fidatech/afghan-datepicker/styles.css';

if (document.querySelector('#invoice_date')) {
  new AfghanDatepicker('#invoice_date', {
    locale: 'fa-AF',
    calendar: 'jalali'
  });
}
Laravel validation 
$validated = $request->validate([
    'invoice_date' => ['required', 'date_format:Y-m-d'],
]);

Run your app's normal Vite build. Install the library tarball in the Laravel project's npm dependencies beforehand. This example illustrates integration; the repository does not ship a Laravel service provider.

09 / Frameworks

React and Vue integration

The core datepicker works without a framework. React and Vue can use it directly with their component lifecycle hooks; dedicated wrappers are planned, not included in this release.

React (TypeScript)

DateField.tsx 
import { useEffect, useRef } from 'react';
import { AfghanDatepicker } from '@fidatech/afghan-datepicker';
import '@fidatech/afghan-datepicker/styles.css';

export function DateField() {
  const ref = useRef<HTMLInputElement>(null);

  useEffect(() => {
    if (!ref.current) return;
    const picker = new AfghanDatepicker(ref.current, {
      locale: 'ps-AF'
    });
    return () => picker.destroy();
  }, []);

  return <input ref={ref} name="date" />;
}

Vue 3 (Composition API)

DateField.vue 
<script setup lang="ts">
import { ref, onMounted, onBeforeUnmount } from 'vue';
import { AfghanDatepicker } from '@fidatech/afghan-datepicker';
import '@fidatech/afghan-datepicker/styles.css';

const input = ref<HTMLInputElement | null>(null);
let picker: AfghanDatepicker | undefined;

onMounted(() => {
  if (input.value) picker = new AfghanDatepicker(input.value, {
    locale: 'fa-AF'
  });
});
onBeforeUnmount(() => picker?.destroy());
</script>

<template><input ref="input" name="date" /></template>

11 / Date calculations

Calendar utility functions

The same package exposes strict Gregorian ISO parsing and Jalali conversion helpers for APIs and application logic.

TypeScript 
import {
  toCalendar, fromCalendar, addDays, monthLength,
  weekday, parseISO, todayISO
} from '@fidatech/afghan-datepicker';

toCalendar('2016-04-11');
// { year: 1395, month: 1, day: 23 }

fromCalendar({ year: 1395, month: 1, day: 23 });
// '2016-04-11'

addDays('2024-02-28', 1); // '2024-02-29'
monthLength(1395, 12);    // 30 (Jalali leap year)
weekday('2024-03-20');    // 3 = Wednesday
parseISO('2026-10-19');   // { year: 2026, month: 10, day: 19 }
todayISO();               // Current local Gregorian date

Jalali conversions use the jalaali-js algorithm, which has a bounded supported year range. Check dates independently when legal or official accuracy is required.

13 / Help

Troubleshooting and FAQs

Can I install this from npm today?

Not yet. Build the GitHub repository and use npm pack to install the resulting package tarball into another project. An npm registry release is planned.

Why does the input show a Jalali date but submit Gregorian?

The library separates user-facing calendar display from stored date values. It creates a hidden field using the input's original name and sends Gregorian YYYY-MM-DD.

My local demo is showing an older design. What should I do?

Run git pull --ff-only and npm run build, then hard-refresh the browser with Cmd+Shift+R on macOS. Start a local HTTP server from the project root.

Chrome can't be found during browser tests.

Install Google Chrome or set the CHROME_BIN environment variable to its executable path. Run npm run test for calendar-only tests when Chrome isn't available.

Can I use the component in a commercial project?

Yes. The source is MIT licensed. Keep required copyright and license notices, including applicable third-party notices.
