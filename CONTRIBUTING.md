# Contributing

Thank you for helping make open-source tools more useful to developers in Afghanistan and beyond.

1. Open an issue describing the problem before a large change.
2. Fork this repository and create a focused branch.
3. Install Node.js 20+ and run: npm install
4. Run: npm run check
5. Add tests for conversions, year boundaries, localized text, and regressions.
6. Send a pull request explaining changed behavior and screenshots when UI changes.

## Localization

Please review translations with native speakers. Don't silently treat Dari (fa-AF) as identical to Iranian Persian (fa-IR) or Pashto (ps-AF). Keep dates stored as Gregorian ISO YYYY-MM-DD, with the requested calendar used for display.

## Reporting bugs

Include browser version, locale, selected date, expected/actual results and minimal reproduction. Never attach real customer or medical data.

## Community guidelines

Be respectful and constructive. Harassment and discriminatory conduct are not welcome.
