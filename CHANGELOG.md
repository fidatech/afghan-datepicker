# Changelog

## 0.1.0 — Initial implementation

- TypeScript component with Pashto, Dari, Persian and English locales.
- Jalali/Gregorian date views backed by jalaali-js.
- Gregorian ISO values via hidden HTML input for standard form posts.
- Keyboard navigation, inclusive min/max, digit formatting, themes and browser demo.
- Calendar unit tests and GitHub Actions build checks.

Version 0.1.0 is a repository implementation. The package is not yet published on npm.
